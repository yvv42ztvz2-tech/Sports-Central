SPORTS CENTRAL — SOLO WIKI RACE BUILD

RUN ON WINDOWS
1. Stop the older Sports Central server.
2. Extract this ZIP into a new folder.
3. Open the SPORTS_CENTRAL folder.
4. Double-click RUN_SPORTS_CENTRAL.bat.
5. Open http://127.0.0.1:5000 in Chrome or Edge.

WIKI RACE
- Multiplayer, party codes, room creation/joining, server room APIs and player polling have been removed.
- Wiki Race is single-player only.
- Enter a player name and start a random race.
- Navigate by clicking hyperlinks directly in the article text.
- Back and Forward buttons move through the visited article history.
- The click counter tracks article-link navigation.

OTHER FEATURES
Sports scores, news, teams, player profiles, game center, paper betting and 82–0 draft season remain in the project. Paper betting uses pretend points only and has no monetary value.

TEST STATUS
Python source compilation, JavaScript syntax and ZIP integrity were checked. Actual Wikipedia loading still requires an internet connection and browser testing.
